# Personal Voice Assistant

A Python-based Personal Voice Assistant that can:

- Recognize voice commands
- Open applications
- Search Google
- Open YouTube
- Tell current time
- Respond using Text-to-Speech

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- pywhatkit

## Commands

- Hello
- Time
- Open YouTube
- Open Google
- Search Python Programming
- Open Notepad
- Exit
